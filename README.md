# Football Player Performance Analysis (2022–23)

> An end-to-end data story exploring performance metrics across Europe's "Big Five" leagues using Power BI.

---

## The Story Behind the Project
As a football enthusiast, I wanted to go beyond the scoreboard to see how data defines "dominance" on the pitch. This project analyzes over 2,500 players to identify not just the top scorers, but the playmaking engines and league-wide trends that defined the 2022–23 season.

## Key Discoveries
* **The Haaland Effect:** The data visualizes Erling Haaland's historic season, showing a scoring efficiency curve that sits well above the league average.
* **League DNA:** While the **Premier League** leads in sheer volume (618 goals), the analysis explores how the **Bundesliga** and **Ligue 1** serve as hubs for high-performing younger talent.
* **The Creative Engines:** Beyond goals, I highlighted "unsung heroes" like **Gabriel Vidović** and **Gianluca Gaetano**, whose playmaking metrics stood out in the creative department.

## My Tech Stack
* **Power BI:** To build an interactive experience with dynamic filtering.
* **Power Query:** Used for the heavy lifting—cleaning raw statistics, handling nulls, and normalizing player positions.
* **Data Source:** A comprehensive CSV dataset of the 2022-23 European season.
